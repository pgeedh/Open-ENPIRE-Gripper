# ARX5 Robot Arm STL Models

> 🚧 **Work in Progress**: We are actively developing and test-printing the ENPIRE finger models for the **ARX5** bimanual robot arm and will update this folder shortly!
>
> 💡 **Already have a working design?** If you have already designed, 3D-printed, or tested an ENPIRE adapter for ARX5, we would love your contribution! Feel free to **[submit a Pull Request](https://github.com/pgeedh/Open-ENPIRE-Gripper-nvidia/pulls)** to help make this available to the community.
>
> *Please check our [Rules for Contributing](../../CONTRIBUTING.md) for STL formatting, coordinate orientation, and physical verification guidelines.*

---

## Gripper Specifications
* **Platform**: ARX5 5-DoF / 6-DoF Arm
* **Gripper Interface**: Direct dual lug M3 fastener pattern
* **Stroke**: ~75 mm
* **Best Applications**: Bimanual mobile manipulation, human-robot interaction.
