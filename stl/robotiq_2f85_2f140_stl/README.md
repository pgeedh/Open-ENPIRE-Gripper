# Robotiq 2F-85 / 2F-140 STL Models

This directory contains the 3D printable STL models for **Robotiq 2F-85** and **Robotiq 2F-140** industrial collaborative grippers.

---

## Gripper Specifications
* **Gripper Models**: Robotiq 2F-85 (85mm stroke) / Robotiq 2F-140 (140mm stroke)
* **Grip Force**: Up to 235 N
* **Mounting Interface**: 2× M4 bracket screws with 10 mm center spacing
* **Best Applications**: Industrial pick-and-place, machine tending, high-payload research.

---

## STL File Naming
