# ISO 9409-1 Flange Adapter STL Models

This directory contains 3D printable tool flange adapter plates conforming to the standard **ISO 9409-1** industrial robot wrist specification.

---

## Flange Standards Supported
* **ISO 9409-1-50-4-M6**: 50 mm PCD (4× M6 screws) — used by Universal Robots (UR3e, UR5e, UR10e, UR16e), UFactory xArm 6/7, Doosan, Elite Robots.
* **ISO 9409-1-31.5-4-M5**: 31.5 mm PCD (4× M5 screws) — used by compact collaborative arms.

---

## STL File Naming
* `iso_9409_1_50_4_m6_plate.stl`
* `iso_9409_1_31_5_4_m5_plate.stl`
