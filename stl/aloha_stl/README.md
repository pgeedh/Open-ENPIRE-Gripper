# ALOHA & Mobile ALOHA STL Models

This directory contains the 3D printable STL models for **ALOHA** and **Mobile ALOHA** bimanual robotic arms.

---

## Gripper Specifications
* **Platform**: ALOHA / Mobile ALOHA / Stanford Bimanual Rig
* **Gripper Interface**: ViperX 300 / 650 parallel jaw carriage
* **Stroke**: 60 mm – 80 mm
* **Grip Force**: ~40 N
* **Best Applications**: Fine bimanual teleoperation, imitation learning, and household/lab manipulation.
