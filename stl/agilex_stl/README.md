---

## Gripper Specifications
* **Arm Platform**: AgileX Piper 6-DoF Robotic Arm
* **Gripper Interface**: Dual locating pin + M3 fastener slider mount
* **Stroke**: ~70 mm parallel stroke
* **Grip Force**: ~35 N
* **Best Applications**: Bimanual physical AI manipulation, tabletop research, and teleoperation.
