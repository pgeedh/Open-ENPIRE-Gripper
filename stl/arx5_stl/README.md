# ARX5 Robot Arm STL Models

This directory contains the 3D printable STL models for the **ARX5** bimanual robotic arm.

---

## Gripper Specifications
* **Platform**: ARX5 5-DoF / 6-DoF Arm
* **Gripper Interface**: Direct dual lug M3 fastener pattern
* **Stroke**: ~75 mm
* **Best Applications**: Bimanual mobile manipulation, human-robot interaction.

---

## STL File Naming
* `arx5_enpire_finger_left.stl`
* `arx5_enpire_finger_right.stl`
