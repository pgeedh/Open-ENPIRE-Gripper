# Robotiq Hand-E Gripper Adapter Files

This directory is dedicated to the **Robotiq Hand-E** adaptive parallel gripper adapter fingers based on the ENPIRE fingertip geometry.

## Robotiq Hand-E Gripper Specifications
- **Gripper Type**: Precision Parallel Electric Gripper
- **Stroke**: 50 mm (parallel linear stroke)
- **Grip Force**: 20 N to 130 N (programmable)
- **Mounting Interface**: 2× M4/M3 mounting screws per finger (standard Robotiq finger bracket)
- **Repeatability**: 0.02 mm
- **Ideal Applications**: High-precision manipulation, electronic assembly, machine tending, and Physical AI benchmark tasks.
