# Open Arm STL Models

This directory contains the 3D printable STL models for the **Open Arm** open-source robotics platform.

---

## Gripper Specifications
* **Platform**: Open Arm Robotic Arm
* **Gripper Interface**: Modular parallel jaw mount
* **Stroke**: 60 mm – 70 mm
* **Best Applications**: Accessible robotics education, open-source AI manipulation research.
