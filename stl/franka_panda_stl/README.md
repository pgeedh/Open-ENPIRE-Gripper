# Franka Emika Panda / FR3 STL Models

This directory contains the 3D printable STL models for the **Franka Emika Panda / FR3 Hand** parallel gripper.

---

## Gripper Specifications
* **Platform**: Franka Emika Panda / FR3 7-DoF Robot
* **Gripper Interface**: Quick-mount dovetail / M4 slider bolt
* **Stroke**: 80 mm
* **Grip Force**: Up to 70 N continuous
* **Best Applications**: High-precision contact physics, impedance control research.
